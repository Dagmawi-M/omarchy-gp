# Changelog

## Unreleased (0.1.0)

First version.

- Panel with status, gateway, username, IP address and data counters
- One-click connect and disconnect through a built-in openconnect engine;
  the password is kept in the system keyring
- Stays connected: reconnects after a drop and connects again at login
- Traffic window: which connections use the VPN and which go direct, by
  destination, with site names from the local DNS cache and a "check a site" box
- Dashboard with time connected and data used per day
- Account window for the portal, username and password
- `omarchy-gp doctor` to check the setup
- Install, engine setup and uninstall scripts; waybar snippet
